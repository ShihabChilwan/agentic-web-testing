# Comparator v3: Kutt and mern-ecommerce re-compared (11 Nov 2026)

There were no new runs and no model calls. The saved recordings were compared again with the v3 rules (SPEC §7.6, "Comparator v3"). The v3 files are in each suite's `differential-v3/` folder. The v2 files in `differential/` stay untouched, because the scoring protocols reference them by hash.

## Rules added

1. **Path parts that vary.** A path part that differed between correct runs in the same test becomes `:var` when it fits the learned shape. Kutt learned `GET /*`, `PAGE /*` and `END /*`, with a random tail of 6–7 characters, in TC-040, TC-102, TC-116 and TC-117. Mern learned none.
2. **Relative times.** Texts like `0 seconds ago` / `1 second ago` count as noise when they are at most max(120 s, one unit) apart.
3. **HTML element by element.** Each element is compared by its own text and its compared attributes. A changed element is strong; reordered identical elements are no difference.
4. **Different pages at one step.** When two snapshots at the same step share less than half of their lines, their differences are weak (reason `other-page`).

**Left over (not fixed).** TC-110 in x-13 and x-16 has 46 strong lines. Cause: in those runs, the browser cancelled the first `GET /` document load. A cancelled call has no body, so it is left out, and the remaining loads pair by occurrence one place off: logged-in against logged-out. In v2 the same mismatch was 1 strong `(body)` line; element by element it becomes 46.

A fix was tried: count the cancelled calls in the occurrence number. It changed 50 of the 51 mern comparisons and gave Kutt x-17 24 false strong differences, so it was reverted.
